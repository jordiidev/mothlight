Mothlight — guide a luna moth through the night garden. Collect glowing pollen to light the lantern: 25 a night, 3 nights to dawn. Moonpetals give a shield, bats cost a life, combos multiply your score. Fly with WASD or arrows, steer with the mouse, dash with Shift.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — just static files under `game/`.
